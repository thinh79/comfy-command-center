# 🧠 AI Command Center

Repo này là nơi lưu trữ toàn bộ kiến thức, workflow và cấu hình ComfyUI của tôi.
Được thiết kế để chạy tự động trên Vast.ai.

## 🚀 Cách sử dụng trên Vast.ai
Chạy lệnh sau khi thuê máy:
```bash
bash -c "$(wget -qO- https://raw.githubusercontent.com/USER_NAME/REPO_NAME/main/install.sh)"
```
*(Nhớ thay USER_NAME và REPO_NAME bằng link github thật của bạn)*

## 📂 Cấu trúc
- **/workflows**: Chứa các file .json (Basic, ControlNet, Video...)
- **/notes**: Ghi chú kiến thức đã học.
- **install.sh**: Script cài đặt tự động.
